# M Umar Farooq — Portfolio

Personal portfolio website (plain HTML, CSS and JavaScript — no build step).

## Add your profile photo
Save your photo as **`assets/img/profile.jpg`** (square or portrait, around 800×900px).
Until the photo is added, the site shows "UF" initials instead.

## Publish free on GitHub Pages
1. Create a new GitHub repository (for example `portfolio`, or `<your-username>.github.io`).
2. Upload all files in this folder (`index.html`, `assets/`, `README.md`).
3. In the repository go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. After a minute your site is live at `https://<your-username>.github.io/` (or `/portfolio/`).

## Use your own domain later
Buy the domain (e.g. `umarfarooqdev.com`), then in **Settings → Pages → Custom domain** enter it
and add the DNS records GitHub shows you at your domain provider.
